# V-UP! 提案驗證階段：雙人開發與分工計畫
> 狀態：規劃中 | 更新：2026-05-03

根據目前的專案狀態與外部依賴（GitHub 權限、向老師提報的流程），我們需要採用**「敏捷且分階段」**的策略。

核心原則：**在向老師提報前，絕不投入開發 Demo 版的邏輯程式碼（避免做白工）。**

---

## 📅 階段一：準備向老師提報的 MVP（Minimum Viable Pitch）
**目標**：完成首頁（Landing Page）的文案與版面修正，並成功部署到網路上，產生一個可以給老師點擊的網址。

| 任務項目 | 負責人 | 具體工作內容 |
|---------|--------|-------------|
| **1. Landing Page 文案與 CTA 替換** | **你 (與 AI)** | - 修改 `index.html` 的 H1、副標題。<br>- 調整 CTA 按鈕順序（創作者優先）。<br>- 刪除不必要的區塊（如複雜的 How it works、佔位卡片）。 |
| **2. 基礎 UI/UX 優化 (首頁)** | **共同負責** | - 確保修改後的首頁在手機版與電腦版皆排版整齊。<br>- 修正任何破版或視覺不協調的地方。 |
| **3. Netlify 部署與 CI/CD 設定** | **組員** | - 在 Netlify 綁定 GitHub Repository。<br>- 設定建置指令與部署目錄。<br>- 產出專屬的預覽網址（如 `v-up-demo.netlify.app`）。 |
| **4. 準備提報說帖** | **你** | - 準備向老師說明的策略：為什麼我們要做這個 Landing Page，以及接下來 Demo 版與表單驗證的規劃。 |

**✅ 檢核點：** 獲得一個可以順暢瀏覽、文案正確的 Netlify 網址。

---

## 🏛 階段二：向老師（主管）提報 (Milestone)
**目標**：確認目前的「市場驗證策略」與「Demo 試玩版規劃」是否可行。

**行動：**
1. 展示部署在 Netlify 的 Landing Page。
2. 說明目前的修改是為了「蒐集市場反饋（特別是創作者）」。
3. 提案接下來的 Demo Flow 實作（不需要帳號、不接真實金流的沙盒體驗）與 Google Form 反饋機制。
4. **取得老師的同意後，才進入階段三。**

---

## 🚀 階段三：提報後實作（Demo 版與驗證表單）
**目標**：在老師同意後，快速實作出可互動的試玩版，並上線開始蒐集反饋。

| 任務項目 | 負責人 | 具體工作內容 |
|---------|--------|-------------|
| **1. Google Form 表單建立** | **組員** | - 建立包含 3-4 個核心問題的反饋表單。<br>- 取得對外分享的短網址。 |
| **2. 實作 Demo 頁面工具列** | **你 (與 AI)** | - 在 `vtuber_profile.html?id=demo` 頂部加入「試玩點數 500 V點」的工具列 UI。 |
| **3. Payment Modal 沙盒化** | **你 (與 AI)** | - 修改 `js/services/payment.service.js` 或相關邏輯，攔截付款動作。<br>- 實作 LocalStorage 扣款與進度條模擬動畫。 |
| **4. Demo 完成後的 Toast/Modal** | **你 (與 AI)** | - 當試玩贊助完成後，跳出引導視窗。<br>- 將組員做好的 Google Form 網址放入按鈕中。 |
| **5. 試玩版 UI/UX 優化與測試** | **共同負責** | - 測試從 Landing Page 點擊試玩，到完成贊助、填寫表單的完整動線。<br>- 修飾動畫順暢度與 Modal 樣式。 |
| **6. 最終版本部署上線** | **組員** | - 將包含 Demo 功能的程式碼 Push 至 GitHub，觸發 Netlify 自動更新。 |

---

## 💡 給你們的協作建議

1. **GitHub 分支策略**：
   - 組員在設定 Netlify 時，可先確保 `main` 分支是隨時可部署的穩定狀態。
   - 你在修改 Landing Page 時，可以開一個 `feature/landing-page-update` 的分支，改完後發 PR 給組員 Review 並 Merge。
2. **與 AI 的協作**：
   - 階段一的 UI 修改，你可以直接跟我說：「我們現在來改 `index.html` 的文案」，我們就能快速搞定。
   - 階段三的邏輯實作，你可以把邏輯拆成小塊（例如：「幫我寫一段攔截付費按鈕並顯示本地動畫的 JS」），我能提供具體的程式碼。
